Obelisk — A–Z decorative initials

26 transparent SVG illustrations. No font installation is needed.

Use one SVG as an image or paste its SVG paths inline. Inline artwork uses the CSS color property. A separate SVG image is black by default. Keep its proportions when you change its size.

Example:
<img class="initial" src="A.svg" alt="A">fter the rain, the garden grew quiet.
.initial { float: left; height: 6rem; width: auto; margin: .2rem .7rem 0 0; }

The letters were reviewed at 96px and 120px. Larger sizes show the fine engraving more clearly.

Credits, sources, and license paths are in metadata.json and the included notices. Keep the applicable notices when you distribute the artwork.
